# 👗 ZEZA CLOTHING (@zeza_brandn)
> *"your everyday fashion store"*

เว็บไซต์แคตตาล็อกร้านเสื้อผ้าแฟชั่น / เสื้อผ้ามือสองคัดเกรด สไตล์ Apple Store พร้อมระบบจัดการหลังบ้าน (Admin Panel) เพิ่ม ลบ แก้ไข อัปโหลดรูปภาพสินค้า เชื่อมต่อฐานข้อมูล Cloud Firestore & Firebase Authentication

---

## ✨ คุณสมบัติของเว็บไซต์ (Production Ready)
1. **ดีไซน์และมู้ดสไตล์ Apple Store**:
   - พื้นหลัง `#F5F5F7` การ์ดมุมมนพรีเมียม `rounded-3xl`
   - แถบหมวดหมู่สินค้าแบบไอคอน Apple พร้อมระบบกรองสินค้าและ Animation นุ่มๆ
2. **ออกแบบเพื่อรูปถ่ายจริง (Flat-lay)**:
   - กรอบรูปการ์ดสัดส่วน `aspect-[4/5]` มุมมน `rounded-2xl` พร้อม `object-cover`
   - รองรับรูปภาพหลายรูปต่อสินค้า บีบอัดเป็น WebP อัตโนมัติ (ลดขนาดเหลือ ~50-80KB ต่อรูป โหลดเร็ว ประหยัดพื้นที่)
   - หน้าการ์ดมี Hover Reveal สลับแสดงรูปมุมที่ 2 อัตโนมัติ
3. **ระบบสั่งซื้อง่ายๆ (DM to Order)**:
   - คลิกการ์ดเพื่อเปิด Popup ดูสัดส่วนละเอียดและแกลเลอรีรูปภาพ
   - ปุ่มกดคัดลอกชื่อสินค้า พร้อมลิงก์ตรงเข้า Instagram DM `@zeza_brandn`
4. **ระบบแอดมิน (Admin Panel - Firebase)**:
   - **เข้าสู่ระบบ:** ล็อกอินด้วยอีเมลและรหัสผ่านจริงที่สร้างใน Firebase Authentication
   - **เพิ่มสินค้าใหม่:** กรอกข้อมูลและเลือกรูปภาพหลายรูปพร้อมกันได้ทันที
   - **แก้ไข/ลบสินค้า:** กดปุ่มดินสอหรือถังขยะบนการ์ดสินค้าได้ทันที
   - **สลับสถานะด่วน:** คลิกเดียวสลับ "พร้อมส่ง ➔ ติดจอง ➔ ขายแล้ว"
